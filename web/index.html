AFL Parity

Every AFL season since 1897, searching for the first Hamiltonian cycle to occur from its game results. An occurence where Team A beat Team B beat Team C and so on, back around to Team A, with each team 'visited' once and once only. This site shows which seasons found one, the structure of the the first to occur that season, and which seasons one did not occur.

Purposefully built with Python (a notoriously slow language for heavy computation) this implementation successfully computed the first Hamiltonian cycle for every season in under 3 minutes. Rather than relying on raw language speed, the performance came down to deeply understanding the constraints and implementing aggressive, use-case-specific early exits using a hybrid BFS and DFS approach. More details on the methods and optimisations can be found in the README.

Game result data comes from the API at squiggle.com.au — thank you to the team behind it for making this data so easy to work with.
